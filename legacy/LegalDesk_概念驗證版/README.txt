LegalDesk｜法務室作業助手（概念驗證版）
========================================

開啟方式：
1. 直接用 Chrome / Edge 開啟 index.html。
2. 在「專利案件管理」使用新增、編輯、匯入/匯出 CSV。可按「載入假資料」練習。
3. 在「強執狀校對」貼入 Word 的純文字內容，並輸入人工核實的當事人、執行名義案號與本金金額後校對。
4. 可按「載入示範」看見虛構案件中的案號、金額不一致及範本占位符。

重要限制：
* 僅概念驗證，不能代替法務審查或保證書狀可送件。
* 支援貼上文字、匯入 TXT；不直接匯入 DOCX、掃描 PDF。
* 專利紀錄只在目前瀏覽器記憶體，關閉或重整會失去未匯出的內容；務必匯出 CSV 並存入公司核准的共用位置。
* 沒有連線到經濟部智慧財產局，不會自動更新案件狀態、年費或期限。
* 沒有資料庫、伺服器、第三方 AI、追蹤碼或遠端程式庫。
* 示範程式未經公司安全審查。請先只使用虛構或去識別化測試資料，不要輸入機密文件、當事人個資或未公開專利資料。
* 如要正式使用，須先完成主管與資訊安全審核、法務專業確認及使用者測試，訂定主檔版本與交接流程。

建議正式版後續開發：
1. DOCX 原文解析與位置標記（不改寫原件）。
2. 以 Word 或 Excel 案件主檔對照書狀金額／日期／當事人。
3. 可由非工程師在 Excel 設定校對規則。
4. 匯出結果、複核簽名欄與缺失紀錄（不留機敏全文）。
5. 取得公司 IT 許可後安裝在內網、具備授權及備份機制。
