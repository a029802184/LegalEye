# 法眼 LegalEye｜掃描文件核對

## 自動讀取

選擇四種核對流程之一，匯入 PDF、Word、Excel 或一整包 ZIP。預設開啟「自動辨識掃描文件中的文字」。有文字的 PDF 一般直接讀取，掃描頁才用法眼本機辨識。系統會顯示正在讀取第幾頁。原件與本次核對資料由瀏覽器在這台裝置處理。

## 用 Chrome 協助讀取

1. 在公司允許的桌面 Chrome 開啟電腦裡的原始 PDF。保留本機檔案，避開 Lens 與儲存到雲端硬碟。
2. 等該頁文字可以反白後，複製要核對的文字。同一頁有多人時，保留本案人物的姓名、證號等標籤及需核對的欄位。若 Chrome 沒有產生可選文字，改用法眼自動讀取、查看原頁或手動更正。
3. 回法眼按「使用 Chrome 協助讀取掃描文件」。選擇案件、原始 PDF、文件類型與頁碼，貼上或匯入該頁 `.txt`，按「重新核對這一頁」。選錯案件或原頁時，先在案件結果確認配對，再重做。
4. 展開結果的對應欄位。若同時有兩種讀值，按「查看原頁」比對。核實後可用「更正讀取結果」存入原件上的內容。欄位查不到或資料有多種解讀時，使用既有人工覆核與備註。

一筆對應一個案件及原件頁面。多頁分開操作，貼入片段只會補該片段能證明的欄位。案件詳情可展開本頁貼入文字或移除。沒有案件可選時，先確認書狀的文件類型。手機和平板可以匯入本機檔案、查看原件、貼入在核准裝置取得的文字與人工更正。

## 看懂結果

| 看到的結果 | 接著要做什麼 |
|---|---|
| 尚未附上來源文件 | 補上指定文件或檢查檔案分類。 |
| 掃描文字沒讀清楚 | 開啟原頁，在有定位時重讀該欄或改用 Chrome／人工確認。 |
| 頁面有文字，欄位尚未抓出 | 看原頁欄位、貼上帶欄位標籤的文字或人工更正。 |
| 尚未確定對應哪位債務人 | 檢查案號、姓名或證號可見部分，選擇正確來源。 |
| 有兩種讀取結果 | 對照該檔第幾頁及原值後更正。例如 `93巷` 與 `98巷`。 |
| 已由人工確認 | 所填修正只用於當前案件與欄位，核對結果和報告會保留修正紀錄。 |

主按鈕下載 HTML 核對報告，可用瀏覽器列印或另存 PDF。報告預設遮罩身分證、帳號與電話，仍可能含姓名、地址等案件資料，請依公司規定保管。使用完畢可按「清除本次資料」，並依公司規範處理已下載報告、匯入的 TXT 和作業系統剪貼簿歷史。
