# 法眼 LegalEye 使用手冊



 一、開啟系統
- 公司已部署：用 Chrome 或 Edge 開啟公司提供的網址。
- 單機使用：雙擊資料夾中的「啟動法眼.bat」，瀏覽器會自動開啟。使用完關閉黑色視窗即可。
- 不要直接雙擊 `index.html`（瀏覽器會擋住讀取 PDF 所需的功能）。

## 二、專利案件管理
1. 從首頁按「匯入 Excel」，或到「專利案件管理」按「匯入 Excel／CSV」，選取共用資料夾中的主檔。舊版 LegalDesk 匯出的 CSV 也可匯入。
2. 匯入前會顯示預覽：筆數、版本、問題清單。選「取代目前清單」或「合併」。
3. 新增／編輯／刪除案件；勾選多筆可批次改狀態。
4. 「完整性檢查」會列出缺編號、重複、日期格式錯誤、舊狀態、已核准但沒有證書號等問題。
5. 完成後「匯出 Excel」，存回共用資料夾。**網頁不會修改原本的 Excel，只會下載新檔案。**

期限提醒依「下次確認日」「重要期限」分為已逾期、7 天內、30 天內。系統**不會**自行推算法定期限。

## 三、法律文件核對
1. 在首頁選擇文件類型，從上傳區確認所需文件。
2. 「選擇檔案」選取整包 ZIP（或多個 PDF／Word／Excel）。手機與平板會開啟系統檔案選擇器。
3. 在「檔案辨識與確認」查看缺件並更正文件分類，再按「開始核對」。若已產生結果，改選分類會重新核對。
4. 看結果：左邊是債務人／核對單位，右邊是逐項結果。點一項可看「來源 A」「待核書狀 B」的原文、檔名與頁碼，按「查看原頁」看 PDF 原頁。
5. 每一項標記「需修正／誤報／已處理」，可寫備註。
6. 「下載 HTML 報告」存檔；用瀏覽器開啟後可「列印 → 儲存為 PDF」。

流程 B 若送達證書辨識不完整，請在「送達資料」區補上送達方式與日期，再按「套用並重新計算」。
流程 C 若配對錯誤，在債務人詳情中「人工配對」戶籍與帳務資料。

### 快速文字校對（舊版功能）
「法律文件核對」→「快速文字校對」：貼上書狀文字或匯入 TXT／DOCX，輸入人工確認的債權人、債務人、案號、本金後檢查。

## 四、結果狀態
| 標示 | 意思 |
|---|---|
| ✓ 一致 | 依目前規則，在所列來源中找到相同記載 |
| ✕ 不一致 | 兩邊不同，請看原因與原文 |
| ◐ 部分核對 | 例如法院只給遮罩身分證 |
| ○ 缺資料 | 缺檔或沒有該欄位；**不等於正確** |
| ? 辨識失敗 | 掃描不清、OCR 信心低、Excel 公式沒有計算結果 |
| ! 需人工判斷 | 規則無法自動決定 |
| – 不適用 | 來源未提供該欄位，不算錯 |

「全部一致」只代表「未發現符合目前規則的疑點」，最終判斷仍由承辦人員負責。

## 五、送達與利息（流程 B）
- 一般送達：送達日＋1 日起息。寄存送達：寄存日＋11 日起息（例：7/1 寄存 → 7/12）。
- 寄存後提前領取、公示送達、境外送達、方式不明：系統標「需人工判斷」。
- 與法院地點無關；不加 20 日異議期間；確定證明書日期不是送達日。

## 六、手機與平板
- 下載位置：iPhone／iPad 在「檔案」App →「下載項目」；Android 在「下載」。
- 有「分享／儲存到…」按鈕時，可自行選擇存放位置；系統不會自動傳送。
- 大量掃描檔 OCR 建議在桌機處理。

## 七、備份與交接
1. 專利：匯出的 Excel 就是正式備份。
2. 規則：「規則與設定」→「匯出設定（JSON）」。新電腦用「匯入設定」還原。
3. 報告：每次下載 HTML 報告存檔。上傳的文件不會被保存。
4. 交接清單：網址、Excel 主檔位置、設定 JSON 位置、本手冊。

## 八、資安提醒
- 文件只在你的瀏覽器處理，不上傳、不使用外部 AI 或雲端 OCR。
- 系統沒有登入與權限控管；正式使用前請由資安與法務確認部署方式。
- 正式文件請在公司核准的環境中使用。
