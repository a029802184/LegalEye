測試方法說明：
- Edge 無頭模式中，真實檔案下載會自動開啟空白分頁並干擾後續測試，因此 E2E 改為攔截 app 建立的下載連結、讀取 Blob 驗證檔名與內容。
- 網站 CSP 禁止 `eval`，Playwright 的 `waitForFunction` 需要 eval，因此僅在測試設定 `bypassCSP: true`；使用者端 CSP 不受影響。
- 本機 PowerShell 啟動程式（`啟動法眼.bat`）另以 HTTP 請求驗證：首頁、SVG、WASM、CMap 回應正確 MIME，`/../package.json` 回 404。

## 5. 未測試或有限制的項目（請如實看待）

- **未在實體 iPhone／Android 裝置測試**；只在 Edge 以觸控模擬各尺寸視窗。iOS Safari 的下載／分享行為、鍵盤彈出、安全區域仍需真機確認。
- **未使用真實法院文件測試**：抽取規則以常見格式設計，真實文件（不同版面、掃描品質、用語）可能需要調整關鍵字。建議先以去識別化的真實樣本試跑，並記錄誤報／漏報。
- **OCR 準確度未評估**：只驗證 OCR 可離線執行並正確標示「信心過低」。真實掃描檔的辨識率未知，結果一律需對照原頁。
- **Word「頁」的定義**：以明確分頁符號（或 Word 上次排版的分頁標記）切頁；沒有分頁符號、靠自動換頁的文件，頁碼可能與列印版不同（系統會提示）。
- 流程 A、B 的配對以案號為主，介面提供「改文件角色」，但沒有像流程 C 的逐筆人工配對選單。
- PDF 文字層抽取與 OCR 在主執行緒外（PDF.js／Tesseract Worker）；DOCX／XLSX 解析在主執行緒分批進行，極大檔案仍可能短暫卡頓。
- 系統無登入、權限控管與中心化稽核紀錄，不構成企業資安合規。
